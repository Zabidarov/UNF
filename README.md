# UNF# Контроль плановой себестоимости в Заказе покупателя (1С:УНФ)

Решение предназначено для платформы **1С:Управление нашей фирмой** (УНФ). Оно автоматизирует процесс проверки и контроля плановой себестоимости непосредственно в документе «Заказ покупателя» до момента его проведения или отгрузки.

## 🎯 Какую проблему решает?

В стандартном функционале менеджеры могут случайно согласовать заказ с низкой или отрицательной маржинальностью. Данная доработка:
* **Предотвращает кассовые разрывы** и убыточные сделки.
* **Блокирует или предупреждает** пользователя, если плановая себестоимость превышает установленный лимит или цену продажи.
* **Помогает контролировать рентабельность** компании на самом раннем этапе воронки продаж.

## 🚀 Основные возможности (Features)

* **Авторасчет отклонений:** Визуальное отображение плановой себестоимости и маржи прямо в табличной части или форме документа.
* **Гибкая система прав:** Возможность запретить проведение «убыточных» заказов для обычных менеджеров с возможностью согласования у руководителя.
* **Интеграция с демо-базой:** В репозитории приложена база `UNFdemo.М3` с уже настроенным и готовым к демонстрации функционалом контроля.

## 🛠️ Состав репозитория

* `UNFdemo.М3` — демонстрационная база 1С:УНФ с внедренным механизмом контроля себестоимости.
* `.gitignore` — служебные исключения для разработки в среде Git.

## ⚙️ Как запустить и протестировать

1. Склонируйте репозиторий:
   ```bash
   git clone https://github.com
   ```
2. Разверните базу из файла `UNFdemo.М3` в вашей платформе «1С:Предприятие».
3. Откройте раздел **Продажи -> Заказы покупателей**, создайте тестовый документ и проверьте работу контроля при изменении цен или состава номенклатуры.
