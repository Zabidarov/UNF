# Контроль себестоимости и интеграция с демо-CRM (Расширение для 1С:УНФ)

Решение выполнено в виде расширения для платформы **1С:Предприятие** и предназначено для работы с конфигурацией **1С:Управление нашей фирмой** (УНФ). Оно объединяет модуль контроля маржинальности заказов и интеграцию по загрузке контрагентов из внешней CRM-системы.

## 🎯 Какую проблему решает?

1. **Контроль продаж:** Автоматически предотвращает согласование менеджерами убыточных сделок непосредственно в документе «Заказ покупателя» до момента отгрузки.
2. **Интеграция данных:** Убирает рутину ручного ввода клиентов. Расширение УНФ автоматически забирает актуальную базу контрагентов из открытого веб-приложения CRM.

## 🚀 Основные возможности

* **Контроль плановой себестоимости:** Визуальный авторасчет отклонений/маржи в табличной части заказа и блокировка проведения «убыточных» документов для обычных сотрудников.
* **Синхронизация через HTTP API:** Готовый модуль загрузки контрагентов, настроенный на работу с открытым HTTP-сервисом на платформе «1С:Элемент».
* **Свободное подключение:** Интеграция работает напрямую **без авторизации** (не требуются токены или логины/пароли), что упрощает тестирование и развертывание демо-стенда.

## ⚙️ Техническое описание интеграции с CRM

Внешняя демо-CRM развернута в облаке «1С» как публичное приложение без авторизации. Расширение 1С:УНФ обращается к ее открытому HTTP-сервису.

* **URL приложения CRM:** `https://1cmycloud.com`
* **API эндпоинт для получения клиентов:** `https://app-180396338.1cmycloud.com/applications/demo-crm/api/connect/customers/`
* **Тип HTTP-метода:** `GET`
* **Формат данных:** `JSON`

### Пример структуры получаемых данных (JSON):

## 💻 Инструкция по развертыванию и тестированию

Для проверки работы функционала вам понадобятся установленная платформа «1С:Предприятие 8» и демонстрационная база конфигурации УНФ.

### Шаг 1. Подготовка демонстрационной базы
1. Скачайте и установите **бесплатно распространяемую демонстрационную конфигурацию «1С:Управление нашей фирмой»** с официального сайта фирмы «1С» (или портала ИТС).
2. Разверните чистую демо-базу на своей платформе.

### Шаг 2. Подключение расширения `UNFdemo.М3`
1. Склонируйте данный репозиторий: `git clone https://github.com`
2. Откройте вашу демо-базу 1С:УНФ в режиме **Конфигуратор**.
3. В верхнем меню выберите: **Конфигурация -> Расширения конфигурации**.
4. В открывшемся окне нажмите **Действия -> Добавить**, укажите имя по умолчанию и нажмите *ОК*.
5. Выделите созданную строку расширения, нажмите **Конфигурация -> Загрузить конфигурацию из файла...** и выберите файл `UNFdemo.М3` из склонированного репозитория.
6. В свойствах расширения **обязательно снимите галочку «Безопасный режим»**, чтобы модуль загрузки по API мог выполнять внешние HTTP-запросы.
7. Обновите конфигурацию базы данных (клавиша **F7**).

### Шаг 3. Проверка работы
1. Запустите 1С:УНФ в режиме «1С:Предприятие».
2. Перейдите в раздел **Продажи -> Заказы покупателей** для проверки работы механизма контроля плановой маржинальности при редактировании табличной части документов.
3. Откройте консоль регламентных заданий (или перейдите в *Настройки -> Обслуживание -> Регламентные и фоновые задания*) и **запустите регламентное задание «Обмен CRM»**.
4. Расширение в фоновом режиме выполнит HTTP-запрос к API демо-CRM, обработает полученный JSON и автоматически заполнит справочник «Контрагенты» новыми компаниями.
